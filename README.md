# Алиса + Polza.ai на Vercel

Навык Яндекс Алисы с моделью `openai/gpt-oss-20b` через Polza.ai. Основан на [шаблоне alice-gemini-serper-template](https://github.com/ruslanpodzorovraw-collab/alice-gemini-serper-template). При желании можно подключить поиск Serper.

## Развёртывание

1. В [Vercel](https://vercel.com/dashboard) выберите **Add New → Project**, импортируйте свой репозиторий GitHub и нажмите **Deploy**.
2. В проекте откройте **Settings → Environment Variables**. Добавьте для окружения Production:
   - `POLZA_API_KEY` — ваш API-ключ Polza.ai (обязательно).
   - `POLZA_MODEL` — необязательно; по умолчанию `openai/gpt-oss-20b`. Указывайте точный ID модели из каталога Polza.ai.
   - `SERPER_API_KEY` — необязательно; ключ для поиска в интернете.
3. Если переменные добавлены после развёртывания, выберите **Deployments → Redeploy** и дождитесь Ready.
4. К своему домену Vercel добавьте `/api`, например `https://ваш-проект.vercel.app/api`. Откройте адрес: сообщение об успешной проверке означает, что обработчик доступен, но не проверяет ключ и модель.
5. В [Яндекс Диалогах](https://dialogs.yandex.ru/developer/) создайте навык. В Backend укажите этот адрес в поле Webhook URL. Включите хранилище данных навыка для контекста текущего разговора.
6. Проверьте навык на вкладке **Тестирование**. Для проверки голосом настройте приватный навык и войдите на устройстве в тот же аккаунт Яндекса. См. [документацию Яндекса](https://yandex.ru/dev/dialogs/alice/doc/ru/test).

## Как поменять модель

1. Откройте ваш проект в Vercel → **Settings → Environment Variables**.
2. Добавьте или измените переменную `POLZA_MODEL`: её значение — точный ID текстовой модели из каталога Polza.ai, например `openai/gpt-oss-20b`. Выберите окружение Production и сохраните.
3. Откройте **Deployments**, выберите **Redeploy** для последнего Production-развёртывания и дождитесь Ready.
4. Задайте вопрос в тестере Яндекс Диалогов. Если модель недоступна, проверьте её ID, доступ и баланс в Polza.ai, а также логи Vercel.

Если переменная не задана, используется `openai/gpt-oss-20b`. Для каждой новой модели проверьте скорость ответа и её стоимость; не все модели или параметры подходят для голосового навыка.

Ключи храните только в настройках Vercel; не публикуйте их и не отправляйте другим людям. Доступность модели и баланс проверьте в Polza.ai. Вызовы API могут быть платными.

Яндекс ждёт ответ всего 4,5 секунды, включая сетевые задержки. Модель может не успеть ответить; проверьте скорость реальными запросами. Поиск запускается лишь по определённым словам и при превышении короткого времени ожидания пропускается. Контекст хранится в пределах сессии, а не постоянно. Приватность навыка не защищает сам общедоступный webhook от посторонних запросов и расходования средств.
